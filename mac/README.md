# SpermPipeline для Mac (Apple Silicon)

Эта папка — отдельная версия приложения для macOS. Архивируйте и отправляйте только её.

## Установка (один раз)
1. Python 3.12 с https://www.python.org/downloads/macos/ (не из Homebrew: там нет окна tkinter).
2. Fiji для macOS (Apple Silicon), Fiji.app — в «Программы». Лучше с TrackMate 7.14.0, как на ПК, где подбирали настройки.
3. ffmpeg: `brew install ffmpeg`.
4. `install_mac.command`: правый клик → «Открыть» (в первый раз macOS не даёт открыть скрипт двойным кликом). Он поставит библиотеки в папку `.venv` и сделает самопроверку.
   Если macOS пишет, что нет прав на открытие (архив собирали на Windows, и пометка «исполняемый» потерялась):
   открыть «Терминал», набрать `chmod +x ` (с пробелом в конце), перетащить в окно оба файла .command и нажать Enter.
   Или просто: `bash ` + перетащить install_mac.command + Enter.

## Запуск
`run_app.command`. В поле Fiji выбрать папку Fiji.app, затем «Загрузить настройки из файла…» — файл настроек с ПК.

## Проверка
Сначала прогнать одно видео, которое уже обработано на ПК, и сравнить проценты.
Если что-то падает — прислать текст из окна install_mac.command или журнал приложения.

Эта версия ещё не проверялась на настоящем Mac.
